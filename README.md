## 🌙 About The Project

Enchanted Doors is a creative frontend web development project designed to turn a simple website into an interactive fantasy journey.

Visitors can explore magical destinations through beautifully designed doors, discover imaginative environments, and interact with a personal world explorer.

The project focuses on creative UI design, CSS animations, JavaScript interactions, and responsive web development.

## ✨ Features

- **Magical Hero Section** — A cinematic introduction with an animated glowing door.
- **Interactive Door Gallery** — Explore different fantasy-inspired destinations.
- **Animated Environments** — Unique visual themes, lighting effects, stars, and decorative elements.
- **Personal World Explorer** — An interactive guide that introduces the experience.
- **Voice Narration** — Browser-based speech synthesis for the guide.
- **Smooth Navigation** — Smooth scrolling between website sections.
- **Responsive Design** — Designed for desktop, tablet, and mobile screens.
- **Interactive Micro-Animations** — Hover effects, floating elements, and visual transitions.
- **Accessibility Considerations** — Keyboard-friendly interactions and reduced-motion support.

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/nehabhatti9028-collab/door-animation-demo.git
   ```

2. Open the project folder:

   ```bash
   cd door-animation-demo
   ```

3. Open `index.html` in your browser.

You can also open the folder in Visual Studio Code and use the Live Server extension.
